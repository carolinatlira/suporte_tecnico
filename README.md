Bem-vindo ao meu repositório de estudos sobre **Suporte Técnico, Help Desk, Service Desk e Infraestrutura de TI**.

Este projeto reúne guias, artigos e materiais de referência sobre os principais conceitos utilizados no dia a dia de profissionais de suporte técnico.

Além de servir como material de estudo, este repositório também faz parte do meu portfólio profissional na área de Tecnologia da Informação.

---

## 🎯 Objetivos

- Consolidar conhecimentos fundamentais de Suporte Técnico;
- Criar uma base de consulta rápida para estudos;
- Compartilhar conhecimento com a comunidade;
- Demonstrar habilidades técnicas através de documentação;
- Apoiar estudantes e profissionais iniciantes na área.
